Statistical Forecasting Engine
Simple Moving Average (SMA)
Formula
SMAt = (Dt-1 + Dt-2 + ... + Dt-n) / n

// Where n = window size (periods)
// Equal weight to all observations in window

WMAt = Σ(wi × Dt-i) / Σwi
// Weighted: recent periods get higher weight

Single Exponential Smoothing (SES)
Formula
St = α × Dt + (1-α) × St-1

// α (alpha) = smoothing factor [0,1]
// High α → more weight to recent demand
// Low α → smoother, slower to react

Forecast: Ft+1 = St
MAPE = mean(|Dt - Ft| / Dt) × 100

Holt-Winters Triple Exponential Smoothing
Formula — Additive seasonal
Level: Lt = α(Dt/St-m) + (1-α)(Lt-1+Tt-1)
Trend: Tt = β(Lt-Lt-1) + (1-β)Tt-1
Season: St = γ(Dt/Lt) + (1-γ)St-m

Forecast: Ft+h = (Lt + hTt) × St-m+h
// m = seasonal period (e.g. 4 quarters, 12 months)

ARIMA AutoRegressive Integrated Moving Average
ARIMA(p,d,q) — Core equation
φ(B)(1-B)dXt = θ(B)εt

AR(p): Xt = c + φ1Xt-1 + ... + φpXt-p + εt
// p = autoregressive order (past values)

I(d): ΔXt = Xt - Xt-d
// d = differencing order (makes series stationary)

MA(q): Xt = μ + εt + θ1εt-1 + ... + θqεt-q
// q = moving average order (past errors)

SARIMA Seasonal ARIMA
SARIMA(p,d,q)(P,D,Q)[m]
φ(B)Φ(Bm)(1-B)d(1-Bm)DXt = θ(B)Θ(Bm)εt

// Non-seasonal: (p,d,q) same as ARIMA
// Seasonal AR: Φ(Bm) captures yearly patterns
// Seasonal MA: Θ(Bm) captures seasonal errors
// D = seasonal differencing order
// m = seasonal period (4=quarterly, 12=monthly)

AIC = 2k - 2ln(L̂)
// Model selection: lower AIC = better fit

Economic Order Quantity (EOQ)
Wilson's EOQ Formula
EOQ = √(2DS / H)

// D = Annual demand (units/year)
// S = Ordering cost per order ($)
// H = Holding cost per unit per year ($)

Total Cost = DS/Q + QH/2 + DC
// Q = order quantity, C = unit cost
Safety Stock & Reorder Point
Statistical Safety Stock Formula
SS = Z × σLT

σLT = √(LT × σd² + d̄² × σLT²)
// Z = service level z-score
// σ_d = std dev of demand
// d̄ = mean daily demand
// σ_LT = std dev of lead time

ROP = d̄ × LT + SS
// Reorder when stock hits ROP
